AgenticMedicalImagingHelper

Research CLI · TypeScript · LangGraph.js · v1.1.1 · GPL-3.0

An open-source command-line tool that uses a multimodal model to analyse series of medical images and track how findings change across imaging sessions. The reference implementation of a SIME 2026 paper.

Research and education only. Not a medical device. It has had no clinical validation and has no regulatory clearance. Its outputs, including any “treatment ideas”, are experimental model output: not a diagnosis, not medical advice, not a recommendation.

Never use it to make decisions about a real patient. Every output needs review by a qualified clinician and may then be used only for research or teaching. See DISCLAIMER.md.

What it does

  • Image-series analysis. Reads series of images (CT, MRI, X-ray, ultrasound) with optional .txt context files, analyses every image in parallel and merges the findings per series.
  • Temporal evolution. Compares series across imaging sessions and reports each finding as Improving, Stable or Worsening in a combined evolution report.
  • Agentic orchestration. A LangGraph.js fan-out / fan-in graph (analyzeImages, aggregateSeries, analyzeEvolution) with p-limit concurrency control. Output: per-image JSON, per-series Markdown and a combined report.
  • Three providers. Google Gemini by default; OpenRouter as an optional second provider (any vision-capable model, no Google Search grounding); or a local model served by Ollama, vLLM or llama.cpp (default medgemma1.5:4b, no key, no API cost). The default Google model is gemini-3.8-flash; new Google keys cannot call gemini-2.5-flash directly, OpenRouter can.
  • Governance and privacy controls. PHI/PII scan of context text before the first upload, DICOM refusal, an input guard, output sanitisation, a cost cap, and a hash-sealed run manifest with an audit ledger and verify-manifest. They are heuristics and engineering controls: a clean result means “nothing obvious”, never “safe” or “compliant”.
  • Deterministic fairness probing. A rule-based probe records sentences that use a demographic attribute to justify a diagnostic statement, plus a probe for size claims that cannot be measured from a PNG or JPEG. Its measured limits are reported below.
  • Disclaimer in every output. A mandatory field enforced at the TypeScript type level; every Markdown report opens with a clinician-review block.

Get started

Needs Node.js 20+, and a Gemini API key, an OpenRouter key or a local OpenAI-compatible model server. Use only de-identified data; images leave your machine only through the provider call.

git clone https://github.com/andreibesleaga/AgenticMedicalImagingHelper.git
cd AgenticMedicalImagingHelper
npm install
cp .env.example .env   # then set GOOGLE_API_KEY in .env
npm run build
npm run dev -- analyze ./input ./output --concurrency 3 --verbose

Input is a folder with one sub-folder per imaging session. To use another provider set AI_PROVIDER=openrouter or AI_PROVIDER=local. Check a finished run with medical-imaging verify-manifest ./output. Full options, exit codes and environment variables: README.

Use cases

All research or education uses; none is clinical.

  • Research on agentic imaging workflows. A worked reference implementation of parallel per-image analysis, per-series merging and temporal comparison.
  • Benchmarking multimodal models. The same pipeline, prompts and schemas run on Gemini, OpenRouter models and a local MedGemma; the follow-up study compares seven models this way.
  • Reproducible experiments. Fixed cohort selections, SHA-256 checks of every input before upload (--expect-hashes), sealed run manifests and every command listed.
  • Studying governance under regulation. An EU AI Act and NIST AI RMF cross-walk, a threat model and seven decision records, written as an inspectable example of ethically deployed, regulated AI. The mappings are not a certification.
  • Teaching agentic architecture. A small, strictly typed, test-covered LangGraph application with the governance controls in plain view.
  • Local-model experiments. A 4B medical model runs the whole pipeline on a 6 GB laptop GPU at no API cost.

Research results

Descriptive, not diagnostic. The reference labels are NIH text-mined labels (about 90 % accurate), the cohorts are small, no clinician reviewed any image or output, and no accuracy claim and no model ranking follows. Follow-up on the original 1024-px images

After the paper, experiments/sime-full repeated the longitudinal experiment on the original 1024 × 1024 NIH images of the same patients, with seven models including a local MedGemma run on a laptop GPU. In all 320 runs, USD 11.19; every input was checked against the original files’ hashes and every run manifest verified.

  • The paper’s operational results reproduce at 224 px (scaling, call counts, cost within 4 %). Its explanation of its worst result, low resolution, is not supported: full resolution does not fix the worsening cases, and a single run’s verdicts describe one draw.
  • The better/same/worse verdict changes between identical runs. In three unchanged runs, only 2 to 5 of 8 patients kept the same verdict (chart below). A single run cannot support a per-patient verdict claim.
  • Full resolution does not fix the cases that get worse. On the 20-patient worsening-like stratum, Gemini 2.5 Flash scored 1 of 5 at 1024 px; Gemini 3.1 Pro, Qwen3-VL and MedGemma scored 0 of 5.
  • Resolution does change what some models report. Qwen3-VL left 4 of 31 images without findings at 1024 px against 22 at 224 px.
  • Local inference works. MedGemma 1.5 4B ran the whole pipeline at no cost, about 5 to 6 minutes per patient, with more schema rejections (36 of 242 answers in the scaling test).
  • Free tiers are not dependable for experiments. The free OpenRouter Gemma variant was rate-limited on the first patient.
